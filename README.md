### Добро пожаловать в проект корпоративного портала для заказа и учёта внутренних услуг предприятия «ServiceHub»!  
**Назначение** - портал предназначен для автоматизации и упорядочивания процессов заказа внутренних услуг компании. Система позволяет сотрудникам легко запрашивать необходимые сервисы, а ответственным подразделениям — эффективно управлять заявками, вести учёт и анализировать нагрузку.
